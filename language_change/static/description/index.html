Switch Odoo's interface language with a single click from the top navigation bar — no need to dig through user preferences.

Key Features

🌍

Navbar Integration

Language selector appears directly in the top navigation bar for instant, always-visible access.

⚡

Instant Switching

One click switches the interface language — the page reloads immediately in the selected language.

🗣

All Installed Languages

Shows all languages activated in your Odoo instance — activate more in Settings → Translations.

🎯

Zero Configuration

Works out of the box after installation — no settings, no extra setup required.

Installation & Usage

  1. Install the module from the Apps menu.
  2. Activate languages under Settings → Translations → Languages.
  3. The language switcher appears automatically in your navbar.
  4. Click it to instantly switch between languages.

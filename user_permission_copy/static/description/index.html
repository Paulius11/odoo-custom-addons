Streamline user onboarding by copying all permissions from one user to another in seconds — no manual group assignment needed.

Key Features

👥

Quick Replication

Copy all security groups and access rights from a source user to one or more targets.

🎯

Wizard Interface

Simple guided wizard with clear steps — select source, select targets, confirm.

🔒

Complete Transfer

Transfers all security groups, access rights, and record rule assignments at once.

✅

Safe by Design

Confirmation dialog prevents accidental changes. Existing permissions are replaced, not merged.

Installation & Usage

  1. Install the module from the Apps menu.
  2. Go to Settings → Users & Companies → Users.
  3. Select a user and click Copy Permissions.
  4. Choose the target user(s) and confirm.

Set up a new colleague in seconds: copy every access right from someone in the same role instead of ticking groups one by one.

Odoo 18.0 Community & Enterprise Free · LGPL-3

See it in action

The wizard shows both users' groups side by side before anything changes.

Key features

One button on the user

Copy Permissions on the user form starts from that user.

Groups and companies

Copies security groups, allowed companies and the default company.

Compare first

See the source's groups next to the target's current ones before you confirm.

Safe by design

Administrators only, a confirmation tick, and the main admin can never be overwritten.

Get started

  1. Install User Permission Copy from the Apps menu.
  2. Open the user to copy from in Settings › Users & Companies › Users and click Copy Permissions.
  3. Pick the target user, tick the confirmation and click Copy Permissions.

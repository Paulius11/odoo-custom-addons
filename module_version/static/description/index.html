Track installed module versions, detect available upgrades, and maintain a complete audit trail of all module lifecycle events in your Odoo instance.

Key Features

📊

Version Display

Shows the current installed version for all modules directly in the Apps list.

🔄

Upgrade Detection

Compares the disk version (manifest) against the database version to flag available upgrades.

📝

Complete History

Full audit trail of every installation, upgrade, and uninstallation with timestamps and users.

🔍

Search & Filter

Filter module history by operation type (Install / Upgrade / Uninstall), date, or user.

👤

User Tracking

See exactly who performed each operation — essential for accountability in shared environments.

📺

App Store Check

Check for newer versions available in the Odoo App Store directly from the module list.

Installation & Usage

  1. Install the module from the Apps menu.
  2. Version information appears automatically in the module list.
  3. View the full history at Settings → Technical → Module Upgrade History.
  4. Use the App Store Check button to compare against the latest available versions.

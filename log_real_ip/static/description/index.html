🌐

X-Forwarded-For

Reads the standard reverse-proxy forwarding header to extract the originating client IP.

🛠

X-Real-IP Fallback

Falls back to the X-Real-IP header — the nginx convention — when X-Forwarded-For is absent.

🔒

Proxy Mode Only

The patch is applied only when proxy_mode = True in odoo.conf. Zero impact on direct setups.

⚡

Zero Overhead

A single startup monkey-patch. No database writes, no configuration UI, no performance cost.

Installation & Setup

  1. Copy or install the log_real_ip module into your addons path.
  2. Enable proxy_mode = True in your odoo.conf.
  3. Install the module from the Apps menu.
  4. Restart Odoo — real IPs will appear in werkzeug access logs immediately.
